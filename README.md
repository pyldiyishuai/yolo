# 视障人士环境感知与识别系统

基于改进 YOLOv8、Vue 3 与 Python FastAPI 的本地部署式视障辅助软件系统，面向视障人士环境感知、风险预警、语音交互与紧急求助场景。

---

## 1. 项目简介

本系统围绕“环境识别 + 风险提示 + 语音交互 + 紧急求助 + 本地配置 + 日志留痕”构建，支持浏览器端摄像头采集、目标识别、语音播报、联系人管理、求助记录管理等能力，适合作为毕业设计、软著申报、项目答辩与演示系统使用。

系统采用前后端分离结构：
- 前端负责页面交互、语音控制、权限调用、无障碍展示；
- 后端负责目标检测、风险评估、日志记录、系统状态管理；
- 数据层采用 `localStorage + SQLite` 的轻量本地存储方案；
- 部署方式以本地部署为主，无需云端服务器即可运行。

## 3. 核心功能概览

| 功能模块 | 功能说明 |
|------|------|
| 系统首页模块 | 展示系统状态、功能入口、运行情况与快捷操作 |
| 环境监测模块 | 调用摄像头采集图像，进行目标识别与结果展示 |
| 目标识别模块 | 基于 YOLOv8 对环境目标进行检测与分类 |
| 距离方向判断模块 | 输出目标距离区间、方位信息 |
| 风险预警模块 | 对识别结果进行高/中/低风险评估并提示 |
| 语音交互模块 | 支持唤醒词、指令识别与 TTS 语音播报 |
| 参数设置模块 | 支持语速、音量、反馈模式等参数配置 |
| 紧急联系人模块 | 支持紧急联系人新增、删除与本地保存 |
| 应急求助模块 | 支持一键求助、定位获取与求助通知 |
| 日志管理模块 | 记录识别日志、风险日志、求助记录 |
| 数据统计模块 | 统计识别次数、风险事件、求助记录等数据 |
| 无障碍支持模块 | 支持高对比度、大按钮、ARIA 语义化与键盘操作 |

## 5. 快速启动

### 5.1 后端依赖安装

```powershell
cd backend
python -m pip install -r requirements.txt
```

### 5.2 启动后端

```powershell
cd backend
python -m uvicorn main:app --host 127.0.0.1 --port 8000
```

### 5.3 启动前端

```powershell
cd frontend
npm install
npm run dev
```

前端访问地址：`http://localhost:5173`  
后端接口地址：`http://127.0.0.1:8000`  
接口文档地址：`http://127.0.0.1:8000/docs`
